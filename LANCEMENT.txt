========================================================
   GUDLFT - COMMANDES DE LANCEMENT
========================================================

PRE-REQUIS
----------
- Activer l'environnement virtuel avant toute commande :
    env\Scripts\activate

--------------------------------------------------------
1. LANCER L'APPLICATION WEB (Flask)
--------------------------------------------------------
  Executer ces commandes l'une apres l'autre dans PowerShell :

    $env:FLASK_APP = "server"
    $env:FLASK_ENV = "development"
    flask run

  Version en une seule ligne :

    $env:FLASK_APP="server"; $env:FLASK_ENV="development"; flask run

  -> Ouvrir le navigateur sur : http://127.0.0.1:5000
  -> Pour arreter le serveur : Ctrl+C

  Emails de connexion disponibles (clubs) :
    - john@simplylift.co
    - admin@irontemple.com
    - kate@shelifts.co.uk

  Identifiants de l'administration :
    - URL         : http://127.0.0.1:5000/admin/login
    - Email       : admin@gudlft.com
    - Mot de passe: admin1234

--------------------------------------------------------
2. LANCER LES TESTS UNITAIRES
--------------------------------------------------------
    pytest tests/

  Avec rapport de couverture de code :
    pytest --cov=server tests/

  Avec rapport HTML detaille :
    pytest --cov=server --cov-report=html tests/
    -> Ouvrir htmlcov/index.html dans le navigateur

--------------------------------------------------------
3. VERIFIER LA CONFORMITE PEP8 (Flake8)
--------------------------------------------------------
    flake8 server.py tests/

--------------------------------------------------------
4. INTERFACE ADMINISTRATION
--------------------------------------------------------
  -> Ouvrir le navigateur sur : http://127.0.0.1:5000/admin/login
  -> Identifiants par defaut :
       Email       : admin@gudlft.com
       Mot de passe: admin1234
  -> Pensez a modifier ces identifiants dans admin.json.

--------------------------------------------------------
5. TEST DE PERFORMANCE (LOCUST)
--------------------------------------------------------
  Demarrer l'application Flask, puis lancer Locust :

    locust -f locustfile.py --host http://127.0.0.1:5000

  -> Ouvrir http://localhost:8089
  -> Renseigner 6 utilisateurs et un taux d'apparition de 1 utilisateur/s.

  Mode sans interface graphique (6 utilisateurs, 30 secondes) :

    locust -f locustfile.py --headless -u 6 -r 1 -t 30s --host http://127.0.0.1:5000
